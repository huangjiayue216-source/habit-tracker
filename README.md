# 习惯打卡

一个单文件、零依赖的习惯打卡网页。双击用浏览器打开就能用：不需要安装任何东西、不需要服务器、不联网。

## 功能

- 添加想坚持的习惯（例如 上厕所 / 运动 / 睡觉），点一下就完成打卡
- 顶部进度环显示「今日完成 / 总数」，全部完成时会有鼓励文案
- 每个习惯显示「连续 N 天」，以及最近 7 天的完成情况
- 可以点最近 7 天的圆点补打卡；未来日期和习惯创建之前的日期不可点
- 支持就地重命名；删除习惯时保留历史记录，并在「最近 7 天」里标记为「已删除」
- 自动跟随系统的深色 / 浅色主题，手机窄屏到 320px 也不溢出

## 使用

在线访问：https://huangjiayue216-source.github.io/habit-tracker/

也可以直接把 `index.html` 下载下来双击打开，效果完全一样。

## 数据说明

打卡数据保存在浏览器本地（localStorage，键名 `habitTracker.v1`），不会上传到任何服务器：

- 换浏览器、换设备或清理浏览器缓存后，数据不会跟随
- 无痕模式下无法保存，页面顶部会给出提示
- 在线使用时，每个访客看到的是各自的打卡数据
